CEPHIONIX — COMPLETE SELF-HOSTING EXPORT

This package contains the complete editable static website, including Homepage, About, Privacy Policy, styles, JavaScript, all image assets, animations, CRM panel, and portfolio.

DEPLOY
Extract this ZIP and upload the contents (index.html, about.html, privacy.html, app.js, pages.js, style.css and assets/) to your hosting web root, often public_html or www. index.html must be at that root. No build command, database, API key, Node server, or ChatGPT subscription is required to run these exported files.

For a static hosting service, choose the folder containing index.html as the publish directory. Enable HTTPS through your hosting provider.

DOMAIN
Use the DNS records provided by YOUR chosen hosting provider for www.cephionix.com. If you already added the earlier ChatGPT Sites CNAME for www, replace it with your new host's value. The OpenAI verification TXT records are not needed for this independent deployment. Preserve unrelated DNS records, especially email MX records. Configure cephionix.com to redirect to www.cephionix.com through your host if desired.
